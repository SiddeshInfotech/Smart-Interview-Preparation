# Smart-Interview-Preparation
## Tech Stack

Smart Interview Preparation Portal is an AI-powered web application designed to help candidates prepare for technical interviews through resume analysis, coding assessments, interview scheduling, and performance analytics.

- **Frontend/** contains the React.js application built with Tailwind CSS.
- **Backend/** contains the Django REST API and business logic.
- **Database/** uses MySQL for storing application data.
- **AI/** integrates Google Gemini API for intelligent features.

This root README provides an overview of the project. Detailed setup instructions should remain inside the respective frontend and backend folders.

# Installation

## Clone Repository

```bash
git clone <repository-url>
cd Smart-Interview-Preparation-Portal
```

## Frontend Setup

```bash
cd Frontend
npm install
npm run dev
```

## Backend Setup

```bash
cd Backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

## Database Setup

- Install MySQL
- Create a new database
- Configure the `.env` file
- Run Django migrations
